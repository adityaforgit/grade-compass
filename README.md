# Grade Compass

Grade Compass is a student-focused academic performance calculator built to simplify marks calculation and semester exam planning, especially for MAKAUT students.

## Features

* Subject-wise marks and grade calculation
* CA1, CA2, ECA and WCA calculation
* Automatic internal marks calculation out of 30
* End-Semester Examination marks calculation
* Required ESE marks for different target grades
* Automatic final score and grade calculation
* Grade point calculation
* Real-time calculation as marks are entered
* Input validation to prevent invalid marks
* Clean, minimal and student-friendly interface
* Responsive design for desktop, tablet and mobile

## Who Can Benefit?

Grade Compass is useful for college students who want to track their academic performance, understand their current internal marks, and plan how much they need to score in their End-Semester Examination.

It is particularly useful for **MAKAUT students** following the continuous assessment structure.
